## 实施步骤

### Step 1：`tools/static_scan_bundles.py`（新建，python-ba 运行）

UnityPy 扫 295 bundle 出日文候选：

- `UnityPy.config.FALLBACK_UNITY_VERSION = "6000.0.59f2"`（bundle 内无版本号，计划书既定）
- 遍历每个 bundle 的 MonoBehaviour 对象原始字节（`obj.get_raw_data()`），正则扫 UTF-8 日文串：假名区段 + CJK 汉字区段（**含纯汉字**），并向两侧带出紧邻的 ASCII 可打印段（TMP 标签、数字、百分号）
- 过滤：含 CJK、长度 ≤ `--max-chars`（默认 80）、非词典已有 key/已有译文/patterns 命中；跨 bundle 去重计数
- 产出 `static_scan/static_candidates.json`：`{key: {"count": N, "bundles": M}}`；同时打印统计（候选数、来源 bundle 数）供目检噪声率

### Step 2：跑 Il2CppDumper 拿字符串字面量（一次性命令，副产物并入）

```
Il2CppDumper-win-v6.7.46\Il2CppDumper.exe ^
  <副本>\GameAssembly.dll <副本>\muv_luv_girlsgarden_cl_Data\il2cpp_data\Metadata\global-metadata.dat ^
  static_scan\il2cpp
```

- 若产出 stringliteral.json：同套过滤规则解析并入 static_candidates.json（C# 硬编码 UI 串，含纯汉字）
- 若 6.7.46 不产该文件：跳过（bundle 是主力），DummyDll 留档不用于扫描

### Step 3：`tools/translate_static.py`（新建，默认 python 运行）

- 读 `static_scan/static_candidates.json` → **import 复用** `translate_pending`（tp：词典读写/patterns 去重/术语表）与 `translate_pending_google`（mask/unmask/translate_entry/google_translate 哨兵流水线，原样复用）
- 与 google 版唯一差异：**放开无假名限制**（bundle 原文就是日文，不存在运行时"上游已译中文回流"问题）
- 逐条 Google 粗翻 → 合并进 `zh_Hans.json` exact（只补缺不覆盖）+ 追加 `zh_Hans.google_log.json` sidecar
- 沿用：`--dry-run`、`--sleep 0.3` 节流、429 退避重试、Ctrl-C 保存已完成部分
- 跑完提醒 F10 热重载

### Step 4：验证

1. scan 脚本 dry 输出：候选总数 + 随机抽样 30 条目检噪声率（非 UI 日文占比）
2. translate `--dry-run` 确认清单量级后全量跑（可中断续跑）
3. 游戏内 F10 后抽查几个此前未汉化/未访问界面（如各设置子页、商店标签页）

## 风险与兜底

- **原始字节扫描噪声**（误收非 UI 日文/资源名）：翻译后入库无副作用（运行时不命中即闲置条目），抽样目检把关
- **候选量大**（可能上千条 × 0.3s ≈ 几十分钟）：设计为可 Ctrl-C 中断、已完成部分即时落盘，重跑自动跳过已译
- **正则误拼跨字段串**：长度上限 + 抽样目检兜底，异常条目人工从词典删
